# CMake Presets Editor v0.1.4

首个公开的 VSIX 安装包，支持在 VS Code 中可视化编辑 `CMakePresets.json` 和 `CMakeUserPresets.json`。

## 功能与改进

- 生成器列表从本机 CMake 动态读取，过滤已弃用的条目，并标记项目实际使用过的生成器。
- architecture 根据有效 generator（包括继承）联动，读取生成器支持的架构候选。
- 架构冲突以醒目的卡片提示，可直接「清空架构配置」或改为「仅供 IDE 使用」。
- 保留 `architecture.strategy: external`；覆盖继承的架构只影响当前预设，不修改父预设。
- 「用可视化编辑器打开」命令提供深色、浅色主题 SVG 图标。
- 更新构建工具依赖，发布流程在打包前执行依赖审计和全部测试。
- 支持变量补全、继承生效值预览、引用校验及 JSON 最小修改，保留原有缩进和未知字段。

## 安装

1. 下载本 Release 附带的 `cmake-presets-editor-0.1.4.vsix`。
2. 在 VS Code 扩展视图的「…」菜单选择「从 VSIX 安装…」，或执行：

   ```powershell
   code --install-extension cmake-presets-editor-0.1.4.vsix --force
   ```

3. 执行「开发人员：重新加载窗口」。
4. 打开预设文件，执行「CMake Presets: 用可视化编辑器打开」。

附件同时提供 SHA-256 校验文件。需要 VS Code 1.85.0 或更高版本；本机 CMake 可用于发现生成器。

## 发布说明

- 当前 VSIX 的扩展 ID 为 `local.cmake-presets-editor`，不包含对 Visual Studio / Ninja 等工具链的安装。
- VS Code 扩展市场尚未上架，待正式 Publisher ID 和发布认证就绪后另行发布。
- 暂不支持 `include` 多文件合并、`condition` 可视化编辑及 test / package / workflow 预设的表单编辑；未编辑的字段会原样保留。
